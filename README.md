# Cycles-Speed-Hacks
#### ⚡ Cycles Speed Hacks

Speed up your Blender Cycles renders without sacrificing visual quality. **Cycles Speed Hacks** is a lightweight Blender 5.0 add-on designed to optimize render settings, reduce noise, and cut down render times with just a few clicks. 

#### ✨ Features
1. AO factor after 2 bounces
2. caustics turned off
3. Simplify tab enabled and limits texture to 2K
4. etc.


#### 💻 Compatibility

* **Blender Version:** Blender 5.0+
* **Render Engine:** Cycles (CPU)

#### 📥 Installation (Blender 5.0)

1. Download Cycles Speed hacks.zip from this repository (click the file, then click **Download raw file**).
2. Open **Blender 5.0** and go to **Edit > Preferences > Get Extensions** (or **Add-ons**).
3. Click the **dropdown arrow (⌄)** in the top-right corner and select **Install from Disk...**.
4. Select Cycles Speed hacks.zip and click **Install from Disk**.
5. Make sure **Cycles Speed Hacks** is enabled in your Add-ons list.

#### 🚀 How to Use

1.switch Render Engine To Cycles
2. scroll down and find Cycles Speed Hacks and Click Apply Ulltra-fast (2K)
3. press F12 to render

#Note the add-ons sets the device to CPU you might want to switch to GPU if you can
The add-on also sets resolution scale to 75% to speed up stuff you might want to change it but It might increase render times
